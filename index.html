Data Analysis · SQL

World Life Expectancy — SQL Analysis

Question
How has life expectancy changed across 193 countries between 2007 and 2022, and which factors is it linked to?
What I did
Cleaned 2,941 rows in MySQL — removed 3 duplicate records, filled 8 missing status labels and estimated 2 missing values — then answered seven questions with SQL.
What I found
The global average rose from 66.8 to 71.6 years, with a dip in 2020. Developed countries averaged 79.2 years against 66.8 for developing countries.

  • Window functions

  • Self joins

Data Analysis · Big Data

UK Crime — Big Data Analysis

Question
Do three widely repeated claims about UK crime hold up when tested against 65 million police records?
What I did
Processed the records with Apache Spark on an Azure virtual machine, joined them with ONS population data, and used time-series forecasting, correlation and regression.
What I found
Burglary fell by about half between 2011 and 2021, so the claim that it was rising did not hold. Merseyside ranked 5th, not 1st, on the weapons-offence rate used as a firearms measure.
  • Apache Spark (PySpark)
  • Azure
  • Python
  • Spark MLlib
  • SARIMA
